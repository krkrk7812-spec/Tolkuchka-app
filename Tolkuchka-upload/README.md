# Толкучка — український автобазар (гра)

Це повноцінна гра «перекуп авто», яка працює **й на телефоні, й на ПК**, і яку можна зібрати в **справжній APK**.

## Що всередині
- `index.html` — вся гра в одному файлі (відкривається просто в браузері).
- `manifest.json`, `sw.js`, іконки — PWA (можна «Встановити на головний екран», працює офлайн).
- `Models/` — реальні фото машин (`.webp`), які показуються в картках.
- `android/` — готовий нативний Android-проєкт (чистий WebView, без зайвих залежностей).

---

## Спосіб 1. Пограти просто зараз (без нічого не встановлюючи)
Відкрий `index.html` у браузері телефону або ПК. Все працює.
Для офлайн-режиму і значка на робочому столі — роздай папку через локальний сервер (див. нижче).

---

## Спосіб 2. Готова PWA (значок на екрані, як додаток)
1. Поклади цю папку на будь-який безкоштовний хостинг (Netlify Drop, GitHub Pages, Vercel).
2. Відкрий сайт на телефоні → меню браузера → **«Встановити додаток / На головний екран»**.
3. Значок «Толкучка» з'явиться серед твоїх програм і працюватиме офлайн.

> PWA вимагає `https://`. Через `file://` кеш офлайн не працює, але гра працює.

---

## Спосіб 3. Справжній APK (рекомендовано для телефона)

### 3a. Автоматично через GitHub (нічого не встановлювати) — найпростіше
1. Створи репозиторій на github.com і залий туди всю цю папку `perekup-simulator`.
2. Закинь файл `.github/workflows/android.yml` (уже є в проєкті) — він автоматично збере APK.
3. На github.com: вкладка **Actions** → **Build APK** → кнопка **Run workflow** (якщо не запустився сам).
4. Через кілька хвилин у тому ж запуску внизу буде артефакт **Tolkuchka-APK** — скачай `.apk` і встанови на телефон (дозволь «Встановлення з невідомих джерел»).

### 3b. Локально (якщо є Android Studio / SDK)
1. Відкрий папку `android/` в Android Studio.
2. Gradle синхронізується сам (JDK 17).
3. Меню **Build → Build Bundle(s)/APK(s) → Build APK(s)**.
4. APK буде в `android/app/build/outputs/apk/debug/app-debug.apk`.

---

## Технічні дані Android-проєкту
- AGP 8.1.4, Gradle 8.2, Java 17, compileSdk/targetSdk 34, minSdk 22 (Android 5.0+).
- Чистий `WebView` + `WebViewAssetLoader` — гра лежить у `assets/` і відкривається офлайн.
- Портретна орієнтація, повноекранний режим, українська іконка-лаунчер.
- `applicationId`: `com.tolkuchka.game`.
